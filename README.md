# 오늘의 기억을 선물하는 편지, 순록의 편지 💌
순록의 편지는 시간과 공간을 초월하여 마음을 전할 수 있는 특별한 편지 서비스입니다!

글과 음성으로 따뜻한 메시지를 담아, 미래의 나, 사랑하는 사람, 그리고 소중한 친구에게 전달하세요.

### 🌟 순록의 편지 – 시간 속에 당신의 마음을 담아보세요. 🌟

[지금 바로 시작하기 💌](https://www.reindeer-letter.site/)



![alt text](image.png)
- 회원가입 후 내 편지함을 만들고 나만의 순록을 꾸며보세요

![alt text](image-2.png)

- **글 편지**
    - 사진과 배경음악(BGM)을 첨부해 더욱 감성적인 편지를 작성할 수 있습니다.
- **음성 편지**
    - 직접 녹음한 음성으로 진솔한 마음을 전달할 수 있습니다.

![alt text](image-3.png)
- 특정 날짜를 선택해 **미래에 도착할 편지를 예약**할 수 있습니다.
- 설정된 날짜에 맞춰 자동으로 전달되며, 알림을 통해 도착 소식을 확인할 수 있습니다.

![alt text](image-1.png)
- **나의 저장소 공유**
    - 친구나 가족에게 나의 편지 저장소를 공유할 수 있습니다.
- **타인이 남기는 편지**
    - 다른 사람이 나의 저장소에 특별한 편지를 남길 수 있습니다.

![alt text](image-4.png)
